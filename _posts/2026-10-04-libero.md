The Libero GitHub repository will be made public later, with the plugin source, sound-authoring tools and agent skills. I will add the link here when it is ready. The repository will be hosted on GitHub; Google Drive is for plugin builds and sound packs.

Libero is currently a beta release. Bugs and changes are still expected.

## Motivation

When I was younger and started producing music, I often looked for new instruments and sounds, but I kept composing with the same set because most of the plugins I could find were too expensive for a teenager.

I would have liked to create playable instruments myself, but doing that by hand is tedious and complex.

LLM agents can help write code, research sound sources and use audio tools to build playable sound packs. I still need to check the source rights, test the code and listen to the results.

With Libero, I have two main goals:

- The first is to build and develop an environment where agents can follow users’ ideas and explore sound creation and audio engineering. Libero provides a broad set of tools through MCP for sampling, synthesizing and analyzing sounds, with the goal of creating playable instruments for a VST3 plugin.
- AI agents can introduce another cost, bringing us back to the original problem. My second goal is therefore to release free, high-quality Libero sound packs, keep them updated and regularly add new ones. The first bundle is already available at the link below.

[Download Libero and the sound packs on Google Drive ↗](https://drive.google.com/drive/folders/1H8RPLpUjnRy4grvidcRvtLt1DuVlx28L?usp=drive_link) — **Installs** contains the macOS and Windows builds; **Packs** contains the complete sound bundle in two ZIP parts, individual packs and their licenses. The current Base Bundle is version 0.1.6, with 95 instruments in 14 packs. Download both bundle parts and select them together in Libero’s import dialog. The Windows build is a test release. Each build includes its corresponding source archive.

## How to install

Download your plugin build from the [Installs folder](https://drive.google.com/drive/folders/1o06ajqFQ5Xg6Qt3SHa7nXkVN21D4fS2B), then close your DAW. You do not need Python or an AI agent to install Libero or play its sounds.

### macOS

Requires macOS 11 or later. The download supports both Apple silicon and Intel Macs.

1. Extract the macOS ZIP.
2. In Finder, choose **Go → Go to Folder** and open `~/Library/Audio/Plug-Ins/`. Create the folders below if they are missing.
3. Copy the whole `Libero.vst3` bundle into `VST3/`. If your DAW uses Audio Units, copy `Libero.component` into `Components/`.

### Windows

Requires Windows 10 or 11 x64 and a 64-bit DAW that supports VST3. This is a test build.

Run the Windows `Setup.exe` from the Installs folder.

For a manual installation, extract the Windows ZIP and copy the whole `Libero.vst3` folder into `C:\Program Files\Common Files\VST3\`.

If Libero reports that WebView2 is missing, install the [Microsoft WebView2 Evergreen Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) and reopen your DAW.

### Load the sounds

1. Reopen your DAW, rescan its plugins if needed, and load Libero as an instrument.
2. Download **both Base Bundle ZIP parts** from [Packs](https://drive.google.com/drive/folders/1aOazeWahV1ejrFAYoCrjCu5ErglAob9Z). Keep them zipped. You can also choose individual `.liberobank` files from [Single Packs and terms](https://drive.google.com/drive/folders/1K3xwuBQd_-S2MKIzE9qv2Ba1qsnV8qSm).
3. In Libero, open **Library → Import**. Select both bundle parts together, or the individual pack files.
4. Review the import summary and confirm. Already installed versions are skipped; updates replace the whole collection, so back up any personal edits first.

The macOS build is not notarized and the Windows installer is unsigned. The Installs folder includes platform instructions and corresponding source archives.

## **Method**

I built Libero around Python recipes that define each instrument’s samples or synthesis, keyboard range, velocity layers, articulations and MIDI controls. I compile these recipes into sound packs and render test phrases through the same native engine used by the plugin.

The MCP tools let an agent search sample libraries, import SFZ instruments and recordings, generate oscillators and textures, trim and tune samples, align attacks, and prepare release layers. Waveforms, spectrograms and pitch analysis help me check the results. The agent can also load a sound into a running Libero instance, change its parameters and audition notes.

I keep the working instructions in two agent skills, `libero-fast` and `libero-slow`. They describe how to choose sources, build an instrument and check its response across notes and dynamics. I update those instructions with examples from the sounds I keep and the revisions I make after listening.

The authoring tools execute Python with my account’s permissions. I use trusted recipes; the subprocess timeout is not a security sandbox. The plugin and downloaded sound packs can be used without connecting an agent.
